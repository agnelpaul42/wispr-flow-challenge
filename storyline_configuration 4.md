# THE GROWTH OPERATOR RPG (V5)

## Global Interactive Architecture:
1. **The Reigns Mechanic:** The main card is a physical object. When dragged, it must tilt (3D rotation). Do not use floating tooltips. As the card moves, reveal giant, bold typography *behind* the card indicating the choice.
2. **Dynamic Background:** Add a subtle, ambient gradient mesh background to the app that pulses. If the user drags left, the ambient glow shifts Red. If dragged right, it shifts Green.
3. **The 'Runway' Meter:** Add a progress bar at the top right. Wrong choices drop it by 20% with a screen shake. Right choices increase it.
